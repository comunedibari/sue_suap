#attività

	Per le pratiche native CROSS esistenti (dal 2018 ad oggi) 
	va popolato il campo "numero_pratica" nella tabella pratica con il valore progressivo ottenuto 
	ordinando le pratiche per ogni anno e per ogni tipo ordinato per data di ricezione.

##aggiunta
	c'è un dettaglio che non avevo specificato, la generazione del numero progressivo deve considerare 
	anche il comune che nella tabella pratica è identificato dal campo id_comune. 
	Nel caso specifico va tenuto in conto solo il comune di Bari, ma 
	facciamo anche una riflessione sulla possibilità di generalizzare per ogni comune.
